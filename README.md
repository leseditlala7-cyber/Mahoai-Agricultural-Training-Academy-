# Mahoai Agricultural Training Academy Website

A professional business website for Mahoai Agricultural Training Academy, a leading skills development and recruitment organisation in South Africa.

## About Mahoai Agric

Established in 2010, Mahoai Agricultural Training Academy and Projects is a registered and accredited multidisciplinary service provider based in Pretoria, Gauteng. We are a Level 1 BBBEE company (100% female-owned) that bridges the gap between education and employment through:

- **Accredited Training Academy**: DHET-registered programs delivering sector-specific skills
- **Strategic Recruitment Agency**: Professional placement services connecting skilled individuals with career opportunities

## Features

- **Responsive Design**: Fully optimized for mobile, tablet, and desktop
- **Professional Blue Branding**: Color scheme matching company logo
- **Multiple Sections**:
  - Hero/Landing section
  - About Us with mission and vision
  - 10 Core Services
  - Training Bridge section explaining impact on education-employment gap
  - Meet Our General Manager (Annah Mahoai)
  - Contact information and form
  - Social media links

## Pages Included

1. **index.html** - Main website page with all sections
2. **styles.css** - Complete styling with blue color scheme
3. **script.js** - Interactive features (mobile menu, smooth scrolling, form handling)
4. **assets/** - Images and logos folder (requires manual image uploads)

## Getting Started

1. Clone the repository
2. Add images to the `assets/` folder:
   - `logo.png` - Company logo
   - `training-image-1.jpg` - Training/education image
   - `annah-mahoai.jpg` - General Manager photo
3. Open `index.html` in a web browser
